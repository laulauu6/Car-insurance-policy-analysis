# Car-insurance-policy-analysis
This project is an interactive power BI dashboard built to analyze car insurance policy and claims data. The dashboard provides insights into customer claims, vehicle information, education levels and coverage zones to support better decision making. 

## Tools Used
Power Query (Data cleaning & transformation)
DAX (calculated Measures)
Data Modeling 
Power BI 

## Key Insights 
The dashboard allows dynamic filtering based on customer demographics and policy information 
Provides a comprehensive overview of insurance claims and customer information
